# Blikvanger (v1)

> Agentkaart. Bron: [catalog.json](../../catalog.json); gegenereerd met `node scripts/build-tool-docs.mjs`. Werk bij inhoudelijke wijzigingen eerst de catalogus, het schema en de runtime bij.

## Toepassingen

- Beeldsituaties beoordelen
- Nieuwsberichten kritisch lezen

## Features

- Afbeelding of nieuwsbericht over de volle breedte, of beeld en tekst naast elkaar
- Meerdere vragen per bron, steeds onderaan
- Enkelvoudige keuze, meerdere juiste antwoorden en waar/onwaar
- Feedback, procentuele eindscore, instelbare slaaggrens en herkansing
- Optionele cooldownSeconds met zichtbare afteller tussen pogingen

## Implementatie

Standalone app.js met veilige tekstweergave. Relatieve afbeeldings- en bronpaden worden opgelost ten opzichte van de geladen JSON-URL. Bij meerdere antwoorden moet de selectie exact kloppen; elke vraag telt even zwaar.

- Runtime: [types/blikvanger/v1/](/types/blikvanger/v1/)
- Configuratieschema: [schema.json](/types/blikvanger/v1/schema.json)
- Voorbeeld: [example.json](/types/blikvanger/v1/example.json)

## Configuratie

Gebruik de JSON die via `?data=<publieke-json-url>` wordt geladen. De schema-URL uit de registry is de norm; de lijst hieronder is er voor snel agent-overzicht.

- `cooldownSeconds` (optioneel) — Wachttijd tussen pogingen (seconden): Wachttijd na een antwoordcontrole of volledige quiz, ook na succes. Tijdens de afteller zijn een nieuwe controle en herstart geblokkeerd. Bij 0 of weglaten blijft het bestaande gedrag behouden.
- `titel` (optioneel) — Titel: Titel boven de oefening.
- `introductie` (optioneel) — Introductie: Korte instructie voor de student.
- `slaaggrens` (optioneel) — Slaaggrens (%): Minimaal percentage volledig goed beantwoorde vragen voor afronding.
- `slides` (verplicht) — Slides: Bronnen in de volgorde waarin de student ze ziet.

## API

Laadt ?data=<JSON-URL>; zonder data wordt example.json getoond. Optioneel unique_id activeert shared/completion.js en het certificaatprotocol. Geen Canvas-score-passback. Een nieuwsbericht wordt als tekst in de configuratie opgenomen; bronUrl is een link en haalt geen artikel op.

Algemene iframe-contracten:

- Launch: `/types/blikvanger/v1/?data=<url-encoded JSON-URL>`.
- `unique_id` kan als queryparameter worden meegegeven wanneer de tool instantiecontext of lokale opslag gebruikt; de schema-eis blijft leidend.
- De registry levert `launchUrl`, `schemaUrl` en `exampleDataUrl`; gebruik nooit een onversieerde tool-URL.
- Beoordeelbare tools kunnen via het optionele certificaatprotocol `postMessage` gebruiken; er wordt geen Canvas-score teruggestuurd. Zie [LTI-inzendingen](../../lti-submission.md) voor de grens van die integratie.
