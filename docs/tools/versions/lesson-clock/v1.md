# Lesklok (v1)

> Agentkaart. Bron: [catalog.json](../../catalog.json); gegenereerd met `node scripts/build-tool-docs.mjs`. Werk bij inhoudelijke wijzigingen eerst de catalogus, het schema en de runtime bij.

## Toepassingen

- Resterende lestijd tonen

## Features

- Meerdere lessen met begin- en eindtijd
- Pie-weergave
- Instelbare waarschuwing en flitsinterval

## Implementatie

app.js berekent de resterende tijd aan de hand van de geconfigureerde ISO 8601-tijdstippen.

- Runtime: [types/lesson-clock/v1/](/types/lesson-clock/v1/)
- Configuratieschema: [schema.json](/types/lesson-clock/v1/schema.json)
- Voorbeeld: [example.json](/types/lesson-clock/v1/example.json)

## Configuratie

Gebruik de JSON die via `?data=<publieke-json-url>` wordt geladen. De schema-URL uit de registry is de norm; de lijst hieronder is er voor snel agent-overzicht.

- `title` (optioneel) — Titel: Titel boven de klok.
- `warningSeconds` (optioneel) — Waarschuwingsdrempel (seconden): Vanaf dit aantal resterende seconden wordt de pie rood en pulseert de klok.
- `flashEverySeconds` (optioneel) — Flitsinterval (seconden): Laat de klok in de laatste fase iedere zoveel seconden kort flitsen.
- `finishedTitle` (optioneel) — Titel na afloop: Titel die zichtbaar is als alle lessen voorbij zijn.
- `finishedMessage` (optioneel) — Melding na afloop: Melding die zichtbaar is als alle lessen voorbij zijn.
- `lessons` (verplicht) — Lessen: De lessen die achter elkaar worden getoond. Gebruik ISO-tijdstippen met tijdzone, bijvoorbeeld 2026-09-21T09:00:00+02:00.

## API

Statische iframe-API; geen eigen server-endpoint of score-passback.

Algemene iframe-contracten:

- Launch: `/types/lesson-clock/v1/?data=<url-encoded JSON-URL>`.
- `unique_id` kan als queryparameter worden meegegeven wanneer de tool instantiecontext of lokale opslag gebruikt; de schema-eis blijft leidend.
- De registry levert `launchUrl`, `schemaUrl` en `exampleDataUrl`; gebruik nooit een onversieerde tool-URL.
- Standalone tools zenden geen `postMessage` en geen Canvas-score terug. Zie [LTI-inzendingen](../../lti-submission.md) voor de grens van die integratie.
