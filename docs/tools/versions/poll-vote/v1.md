- Voorkennis peilen
- Klassikale keuze maken

## Features

- Student-, presentatie- en docentweergave
- Meerdere meerkeuzevragen
- Lange antwoorden voor de eerste stem
- Korte labels in live staafgrafiek
- Individuele stemmen corrigeren of wissen

## Implementatie

app.js pollt iedere seconde api.php. De PHP-backend bewaart per unique_id een vergrendelde JSON-sessie buiten de document root (configureerbaar via LEARNING_TOOLS_POLL_VOTE_STORAGE; anders tijdelijke map).

- Runtime: [types/poll-vote/v1/](/types/poll-vote/v1/)
- Configuratieschema: [schema.json](/types/poll-vote/v1/schema.json)
- Voorbeeld: [example.json](/types/poll-vote/v1/example.json)

## Configuratie

Gebruik de JSON die via `?data=<publieke-json-url>` wordt geladen. De schema-URL uit de registry is de norm; de lijst hieronder is er voor snel agent-overzicht.

- `titel` (verplicht) — Titel: De titel die boven de poll wordt getoond.
- `vragen` (verplicht) — Vragen: Een of meer meerkeuzevragen die de docent tijdens de poll kan kiezen.

## API

Live JSON-API: api.php?unique_id=…&action=…. GET state met participantToken; POST init, claim_teacher, join, vote, previous, next, select_question, clear_question, clear_all, set_vote en delete_vote. teacherToken beschermt docentacties.

Algemene iframe-contracten:

- Launch: `/types/poll-vote/v1/?data=<url-encoded JSON-URL>`.
- `unique_id` kan als queryparameter worden meegegeven wanneer de tool instantiecontext of lokale opslag gebruikt; de schema-eis blijft leidend.
- De registry levert `launchUrl`, `schemaUrl` en `exampleDataUrl`; gebruik nooit een onversieerde tool-URL.
- Standalone tools zenden geen `postMessage` en geen Canvas-score terug. Zie [LTI-inzendingen](../../lti-submission.md) voor de grens van die integratie.
