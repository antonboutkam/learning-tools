# Opdrachtcertificaat (v1)

> Agentkaart. Bron: [catalog.json](../../catalog.json); gegenereerd met `node scripts/build-tool-docs.mjs`. Werk bij inhoudelijke wijzigingen eerst de catalogus, het schema en de runtime bij.

## Toepassingen

- Formatieve les afronden
- Ondertekende certificaten inleveren en automatisch controleren

## Features

- Voortgang van vereiste oefeningen op dezelfde pagina
- Feestelijke afronding en naam/klasformulier
- Ondertekende JSON-download met servertijd
- Idempotente uitgifte per poging
- Publieke-sleutelverificatie via CLI

## Implementatie

app.js gebruikt shared/certificate-channel.js voor gecontroleerde same-origin berichten in dezelfde bovenliggende pagina. api.php gebruikt een privaat servermanifest en lib/certificates/service.php voor Ed25519-uitgifte. Zie docs/opdrachtcertificaat.md voor inrichting.

- Runtime: [types/opdrachtcertificaat/v1/](/types/opdrachtcertificaat/v1/)
- Configuratieschema: [schema.json](/types/opdrachtcertificaat/v1/schema.json)
- Voorbeeld: [example.json](/types/opdrachtcertificaat/v1/example.json)

## Configuratie

Gebruik de JSON die via `?data=<publieke-json-url>` wordt geladen. De schema-URL uit de registry is de norm; de lijst hieronder is er voor snel agent-overzicht.

- `groupId` (verplicht) — Opdrachtgroep: Stabiele groepscode; moet overeenkomen met het geregistreerde servermanifest.
- `revision` (verplicht) — Revisie: Verhoog bij gewijzigde opdrachten en registreer een nieuw servermanifest.
- `title` (verplicht) — Titel: Titel van de opdracht en het certificaat.
- `description` (optioneel) — Uitleg: Korte uitleg boven de voortgang.
- `requiredTools` (verplicht) — Vereiste opdrachten: Alle unieke opdrachtinstanties die succesvol afgerond moeten worden. Neem deze certificaattool zelf niet op.

## API

POST api.php met action manifest of issue. Vereist LT_CERTIFICATE_CONFIG buiten de webroot. Geen Canvas-login, AGS of automatische inlevering.

Algemene iframe-contracten:

- Launch: `/types/opdrachtcertificaat/v1/?data=<url-encoded JSON-URL>`.
- `unique_id` kan als queryparameter worden meegegeven wanneer de tool instantiecontext of lokale opslag gebruikt; de schema-eis blijft leidend.
- De registry levert `launchUrl`, `schemaUrl` en `exampleDataUrl`; gebruik nooit een onversieerde tool-URL.
- Beoordeelbare tools kunnen via het optionele certificaatprotocol `postMessage` gebruiken; er wordt geen Canvas-score teruggestuurd. Zie [LTI-inzendingen](../../lti-submission.md) voor de grens van die integratie.
