# Notities (v1)

> Agentkaart. Bron: [catalog.json](../../catalog.json); gegenereerd met `node scripts/build-tool-docs.mjs`. Werk bij inhoudelijke wijzigingen eerst de catalogus, het schema en de runtime bij.

## Toepassingen

- Lesnotities verzamelen
- Reflectie of schetsen

## Features

- Pagina-omslag
- Typ- en penmodus
- Bookmarks
- Meerdere pagina's

## Implementatie

tool.js gebruikt browseropslag (IndexedDB) per notitieblok-id; de id komt uit querystring of configuratie.

- Runtime: [types/notities/v1/](/types/notities/v1/)
- Configuratieschema: [schema.json](/types/notities/v1/schema.json)
- Voorbeeld: [example.json](/types/notities/v1/example.json)

## Configuratie

Gebruik de JSON die via `?data=<publieke-json-url>` wordt geladen. De schema-URL uit de registry is de norm; de lijst hieronder is er voor snel agent-overzicht.

- `notitieblok_id` (optioneel) — Notitieblok ID: Unieke sleutel voor opslag. Gebruik hetzelfde ID om hetzelfde notitieblok opnieuw te openen (ook op andere plekken).
- `layout` (optioneel) — Weergave: Opties voor het formaat/afmetingen van het kladblok op het scherm.
- `title` (optioneel) — Titel: Titel die boven het notitieblok wordt getoond.
- `pagesCount` (optioneel) — Aantal pagina’s: Totaal aantal pagina’s in het notitieblok.
- `bookmarks` (optioneel) — Bookmarks (optioneel): Vooraf gedefinieerde bookmarks (worden bij eerste keer aanmaken evenredig verdeeld over het notitieblok).

## API

Statische iframe-API; geen eigen server-endpoint of score-passback.

Algemene iframe-contracten:

- Launch: `/types/notities/v1/?data=<url-encoded JSON-URL>`.
- `unique_id` kan als queryparameter worden meegegeven wanneer de tool instantiecontext of lokale opslag gebruikt; de schema-eis blijft leidend.
- De registry levert `launchUrl`, `schemaUrl` en `exampleDataUrl`; gebruik nooit een onversieerde tool-URL.
- Standalone tools zenden geen `postMessage` en geen Canvas-score terug. Zie [LTI-inzendingen](../../lti-submission.md) voor de grens van die integratie.
