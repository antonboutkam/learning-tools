# Juiste volgorde (v1)

> Agentkaart. Bron: [catalog.json](../../catalog.json); gegenereerd met `node scripts/build-tool-docs.mjs`. Werk bij inhoudelijke wijzigingen eerst de catalogus, het schema en de runtime bij.

## Toepassingen

- Processtappen oefenen
- Chronologie ordenen

## Features

- Sleepbare items
- Optioneel schudden
- Nakijken en correcte volgorde

## Implementatie

app.js beschouwt de volgorde van items in de JSON als correct antwoord en ondersteunt een starttoestand.

- Runtime: [types/juiste-volgorde/v1/](/types/juiste-volgorde/v1/)
- Configuratieschema: [schema.json](/types/juiste-volgorde/v1/schema.json)
- Voorbeeld: [example.json](/types/juiste-volgorde/v1/example.json)

## Configuratie

Gebruik de JSON die via `?data=<publieke-json-url>` wordt geladen. De schema-URL uit de registry is de norm; de lijst hieronder is er voor snel agent-overzicht.

- `title` (verplicht) — Titel: Korte titel die boven de opdracht wordt getoond.
- `shuffle` (optioneel) — Shuffle startvolgorde: Als dit aan staat, worden de items bij het starten door elkaar gehusseld (de correcte volgorde blijft de oorspronkelijke volgorde in `items`).
- `showCheck` (optioneel) — Toon controleknop: Toon een knop waarmee studenten hun antwoord kunnen controleren.
- `showCorrectOnCheck` (optioneel) — Toon feedback bij controleren: Markeer items als goed/fout wanneer er gecontroleerd wordt.
- `initialState` (optioneel) — Startmodus: `re-order`: items staan al in een lijst en kunnen worden herschikt. `empty`: lege plekken + een pool met opties die je naar de plekken sleept.
- `image` (optioneel) — Afbeelding (optioneel): Afbeeldings-URL die boven de opdracht wordt getoond. Mag ook relatief zijn.
- `imageAlt` (optioneel) — Afbeelding alt-tekst: Korte beschrijving voor screenreaders (aanbevolen als je een afbeelding gebruikt).
- `imageCaption` (optioneel) — Afbeelding bijschrift: Tekst onder de afbeelding.
- `items` (verplicht) — Items: De items in correcte volgorde (zoals ze beoordeeld moeten worden).

## API

Statische iframe-API; geen eigen server-endpoint of score-passback.

Algemene iframe-contracten:

- Launch: `/types/juiste-volgorde/v1/?data=<url-encoded JSON-URL>`.
- `unique_id` kan als queryparameter worden meegegeven wanneer de tool instantiecontext of lokale opslag gebruikt; de schema-eis blijft leidend.
- De registry levert `launchUrl`, `schemaUrl` en `exampleDataUrl`; gebruik nooit een onversieerde tool-URL.
- Standalone tools zenden geen `postMessage` en geen Canvas-score terug. Zie [LTI-inzendingen](../../lti-submission.md) voor de grens van die integratie.
