# Goed of fout (v1)

> Agentkaart. Bron: [catalog.json](../../catalog.json); gegenereerd met `node scripts/build-tool-docs.mjs`. Werk bij inhoudelijke wijzigingen eerst de catalogus, het schema en de runtime bij.

## Toepassingen

- Beeldsituaties beoordelen

## Features

- Groene en rode antwoordknop
- Instelbare randomisatie en slagingsgrens
- Procentuele eindscore en herkansing

## Implementatie

app.js laadt situaties uit JSON en beoordeelt de antwoorden in de browser.

- Runtime: [types/goed-of-fout/v1/](/types/goed-of-fout/v1/)
- Configuratieschema: [schema.json](/types/goed-of-fout/v1/schema.json)
- Voorbeeld: [example.json](/types/goed-of-fout/v1/example.json)

## Configuratie

Gebruik de JSON die via `?data=<publieke-json-url>` wordt geladen. De schema-URL uit de registry is de norm; de lijst hieronder is er voor snel agent-overzicht.

- `titel` (optioneel) — Titel: Titel bovenaan de oefening.
- `introductie` (optioneel) — Introductie: Korte uitleg die onder de titel wordt getoond.
- `vragenRandomiseren` (verplicht) — Vragen randomiseren: Zet aan om bij iedere poging een willekeurige selectie en volgorde te gebruiken.
- `aantalVragen` (verplicht) — Aantal te stellen vragen: Aantal situaties dat de student per poging krijgt. Als er minder situaties beschikbaar zijn, worden alle beschikbare situaties gebruikt.
- `minimaalGoed` (verplicht) — Minimaal aantal antwoorden goed: Aantal goede antwoorden dat nodig is voor een voldoende. Dit kan niet hoger zijn dan het aantal gestelde vragen.
- `situaties` (verplicht) — Situaties: De afbeeldingen met optionele vraag en het juiste antwoord.

## API

Statische iframe-API; geen eigen server-endpoint of score-passback.

Algemene iframe-contracten:

- Launch: `/types/goed-of-fout/v1/?data=<url-encoded JSON-URL>`.
- `unique_id` kan als queryparameter worden meegegeven wanneer de tool instantiecontext of lokale opslag gebruikt; de schema-eis blijft leidend.
- De registry levert `launchUrl`, `schemaUrl` en `exampleDataUrl`; gebruik nooit een onversieerde tool-URL.
- Standalone tools zenden geen `postMessage` en geen Canvas-score terug. Zie [LTI-inzendingen](../../lti-submission.md) voor de grens van die integratie.
