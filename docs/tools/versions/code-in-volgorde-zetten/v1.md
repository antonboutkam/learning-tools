# Code in volgorde zetten (v1)

> Agentkaart. Bron: [catalog.json](../../catalog.json); gegenereerd met `node scripts/build-tool-docs.mjs`. Werk bij inhoudelijke wijzigingen eerst de catalogus, het schema en de runtime bij.

## Toepassingen

- Programmeerstappen ordenen
- Code met afleiders bespreken

## Features

- Sleepbare coderegels
- Afleiders zonder positie
- Nakijken en juiste antwoord tonen

## Implementatie

app.js bouwt twee codekolommen en valideert de volgorde aan de hand van positie in de configuratie.

- Runtime: [types/code-in-volgorde-zetten/v1/](/types/code-in-volgorde-zetten/v1/)
- Configuratieschema: [schema.json](/types/code-in-volgorde-zetten/v1/schema.json)
- Voorbeeld: [example.json](/types/code-in-volgorde-zetten/v1/example.json)

## Configuratie

Gebruik de JSON die via `?data=<publieke-json-url>` wordt geladen. De schema-URL uit de registry is de norm; de lijst hieronder is er voor snel agent-overzicht.

- `toolTitle` (optioneel) — Tooltitel (kop bovenaan): Titel die helemaal bovenaan de tool staat. Laat leeg om de standaardtitel te gebruiken.
- `title` (verplicht) — Titel: Korte titel die boven de opdracht wordt getoond.
- `description` (optioneel) — Beschrijving: Korte uitleg voor de student (optioneel).
- `shuffle` (optioneel) — Shuffle regels: Als dit aan staat, worden alle regels links door elkaar gezet bij het starten.
- `showCheck` (optioneel) — Toon controleknop: Toon een knop waarmee studenten hun antwoord kunnen controleren.
- `showCorrectOnCheck` (optioneel) — Toon goed/fout feedback: Markeer de plekken rechts als goed/fout na controleren.
- `regels` (verplicht) — Code-regels: Alle regels die links getoond worden. Vul `positie` in voor regels die onderdeel zijn van de oplossing. Laat `positie` leeg voor afleiders.

## API

Statische iframe-API; geen eigen server-endpoint of score-passback.

Algemene iframe-contracten:

- Launch: `/types/code-in-volgorde-zetten/v1/?data=<url-encoded JSON-URL>`.
- `unique_id` kan als queryparameter worden meegegeven wanneer de tool instantiecontext of lokale opslag gebruikt; de schema-eis blijft leidend.
- De registry levert `launchUrl`, `schemaUrl` en `exampleDataUrl`; gebruik nooit een onversieerde tool-URL.
- Standalone tools zenden geen `postMessage` en geen Canvas-score terug. Zie [LTI-inzendingen](../../lti-submission.md) voor de grens van die integratie.
