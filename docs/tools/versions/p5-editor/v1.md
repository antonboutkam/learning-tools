# p5.js editor (v1)

> Agentkaart. Bron: [catalog.json](../../catalog.json); gegenereerd met `node scripts/build-tool-docs.mjs`. Werk bij inhoudelijke wijzigingen eerst de catalogus, het schema en de runtime bij.

## Toepassingen

- Creative coding met p5.js
- JavaScript-sketches onderzoeken en aanpassen

## Features

- Configureerbare demo-JavaScript
- Live of handmatige preview
- Lokale opslag per unique_id
- Stoppen en resetten
- Sandbox zonder same-origin of netwerktoegang

## Implementatie

app.js bouwt voor iedere run een nieuwe sandbox-iframe met lokaal gebundelde p5.js. De runner heeft alleen allow-scripts, een opaque origin en een beperkende Content Security Policy; de hoofdtool valideert statusberichten op bron, origin, type en token.

- Runtime: [types/p5-editor/v1/](/types/p5-editor/v1/)
- Configuratieschema: [schema.json](/types/p5-editor/v1/schema.json)
- Voorbeeld: [example.json](/types/p5-editor/v1/example.json)

## Configuratie

Gebruik de JSON die via `?data=<publieke-json-url>` wordt geladen. De schema-URL uit de registry is de norm; de lijst hieronder is er voor snel agent-overzicht.

- `unique_id` (optioneel) — Unieke ID (optioneel): Stabiele sleutel voor deze tool-instance. Hiermee worden wijzigingen van de student alleen in deze browser opgeslagen.
- `title` (optioneel) — Titel (optioneel): Titel boven de p5.js-editor.
- `intro` (optioneel) — Instructie (optioneel): Korte opdracht of uitleg boven de editor.
- `demoJavaScript` (verplicht) — Demo-JavaScript: Startcode die in de editor verschijnt en als p5.js-sketch in de geïsoleerde preview wordt uitgevoerd. Gebruik bijvoorbeeld setup() en draw().
- `autoRun` (optioneel) — Automatisch uitvoeren (optioneel): Start de preview automatisch na het laden en opnieuw kort nadat de student code wijzigt.
- `readOnly` (optioneel) — Alleen-lezen (optioneel): Toon de demo en preview zonder dat de student de JavaScript kan aanpassen.

## API

Statische iframe-API; lokale browseropslag per unique_id; interne gevalideerde postMessage-statussen vanuit de sandbox; geen eigen server-endpoint of score-passback.

Algemene iframe-contracten:

- Launch: `/types/p5-editor/v1/?data=<url-encoded JSON-URL>`.
- `unique_id` kan als queryparameter worden meegegeven wanneer de tool instantiecontext of lokale opslag gebruikt; de schema-eis blijft leidend.
- De registry levert `launchUrl`, `schemaUrl` en `exampleDataUrl`; gebruik nooit een onversieerde tool-URL.
- Standalone tools zenden geen `postMessage` en geen Canvas-score terug. Zie [LTI-inzendingen](../../lti-submission.md) voor de grens van die integratie.
