# Timeline (v1)

> Agentkaart. Bron: [catalog.json](../../catalog.json); gegenereerd met `node scripts/build-tool-docs.mjs`. Werk bij inhoudelijke wijzigingen eerst de catalogus, het schema en de runtime bij.

## Toepassingen

- Historische tijdlijn
- Projectplanning
- Loopbaan- of toekomstverhaal

## Features

- Horizontaal of verticaal
- Schaal van uur tot decennium
- Faseblokken en jaar-knipsels
- Momenten met afbeelding

## Implementatie

app.js berekent en tekent tijdlijnposities client-side; unique_id is beschikbaar voor instantiecontext.

## Configuratie

Gebruik de JSON die via `?data=<publieke-json-url>` wordt geladen. De schema-URL uit de registry is de norm; de lijst hieronder is er voor snel agent-overzicht.

- `unique_id` (verplicht) — Unieke ID: Unieke sleutel voor deze tool-instance. Wordt ook gebruikt als querystring-parameter in de iframe-URL (`?unique_id=...`).
- `title` (optioneel) — Titel (optioneel): Titel boven de tijdlijn. Laat leeg voor geen titel. Als ook 'Toon datums' uit staat, toont de tool de tijdlijn zonder buitenkader op de volledige iframe-afmeting.
- `intro` (optioneel) — Intro (optioneel): Korte uitleg die boven de tijdlijn wordt getoond.
- `viewport` (optioneel) — Weergave (optioneel): Optionele instellingen om de tijdlijn ruimer te maken (bijv. een minimale hoogte of breedte).
- `direction` (verplicht) — Richting: In welke richting de tijdlijn loopt.
- `scale` (verplicht) — Schaal: Welke schaal de as/ticks gebruikt.
- `showDates` (optioneel) — Toon datums: Toon de periode en schaal bovenaan, de datumlabels op de as en de datum bij elk moment. Zet uit voor een overzicht met bijvoorbeeld alleen projectfasen.
- `startDate` (verplicht) — Startdatum: Start van de tijdlijn. Je mag een datum (YYYY-MM-DD) of een datum+tijd (ISO 8601 date-time) gebruiken.
- `endDate` (verplicht) — Einddatum: Einde van de tijdlijn. Je mag een datum (YYYY-MM-DD) of een datum+tijd (ISO 8601 date-time) gebruiken.
- `yearCuts` (optioneel) — Jaren/periodes knippen (optioneel): Lijst met jaren of jaar-ranges die uit de tijdas geknipt worden. Gebruik komma's, bijvoorbeeld: 1992-2000, 2009-2018, 2025, 2032.
- `phases` (optioneel) — Fasen (optioneel): Optionele faseblokken die als gekleurde band achter de tijdlijn worden getoond, inclusief label.
- `events` (optioneel) — Momenten (optioneel): De momenten op de tijdlijn. Laat leeg of weg als je alleen fasen wilt tonen.

## API

Statische iframe-API; geen eigen server-endpoint of score-passback.

Algemene iframe-contracten:

- Launch: `/types/timeline/v1/?data=<url-encoded JSON-URL>`.
- `unique_id` kan als queryparameter worden meegegeven wanneer de tool instantiecontext of lokale opslag gebruikt; de schema-eis blijft leidend.
- De registry levert `launchUrl`, `schemaUrl` en `exampleDataUrl`; gebruik nooit een onversieerde tool-URL.
- Standalone tools zenden geen `postMessage` en geen Canvas-score terug. Zie [LTI-inzendingen](../../lti-submission.md) voor de grens van die integratie.
