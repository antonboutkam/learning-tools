# Markdown editor (v1)

> Agentkaart. Bron: [catalog.json](../../catalog.json); gegenereerd met `node scripts/build-tool-docs.mjs`. Werk bij inhoudelijke wijzigingen eerst de catalogus, het schema en de runtime bij.

## Toepassingen

- Markdown leren
- Tekst met directe preview schrijven

## Features

- Editor naast live preview
- Read-only-modus
- Standaardbestandsnaam

## Implementatie

app.js rendert Markdown client-side; configuratie kan een unieke instantie identificeren.

- Runtime: [types/markdown-editor/v1/](/types/markdown-editor/v1/)
- Configuratieschema: [schema.json](/types/markdown-editor/v1/schema.json)
- Voorbeeld: [example.json](/types/markdown-editor/v1/example.json)

## Configuratie

Gebruik de JSON die via `?data=<publieke-json-url>` wordt geladen. De schema-URL uit de registry is de norm; de lijst hieronder is er voor snel agent-overzicht.

- `unique_id` (optioneel) — Unieke ID (optioneel): Unieke sleutel voor deze tool-instance. Wordt meestal ook als querystring-parameter meegegeven in de iframe-URL (`?unique_id=...`).
- `title` (optioneel) — Titel (optioneel): Titel boven de editor.
- `intro` (optioneel) — Intro (optioneel): Korte uitleg boven de editor (bijv. instructie voor de student).
- `markdown` (verplicht) — Markdown: De Markdown-tekst die in de editor geladen wordt.
- `defaultFilename` (optioneel) — Standaard bestandsnaam (optioneel): De standaard bestandsnaam die in de download-dialog wordt voorgesteld.
- `readOnly` (optioneel) — Alleen-lezen (optioneel): Als dit aan staat, kan de student de tekst niet aanpassen.

## API

Statische iframe-API; geen eigen server-endpoint of score-passback.

Algemene iframe-contracten:

- Launch: `/types/markdown-editor/v1/?data=<url-encoded JSON-URL>`.
- `unique_id` kan als queryparameter worden meegegeven wanneer de tool instantiecontext of lokale opslag gebruikt; de schema-eis blijft leidend.
- De registry levert `launchUrl`, `schemaUrl` en `exampleDataUrl`; gebruik nooit een onversieerde tool-URL.
- Standalone tools zenden geen `postMessage` en geen Canvas-score terug. Zie [LTI-inzendingen](../../lti-submission.md) voor de grens van die integratie.
