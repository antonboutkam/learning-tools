# Digitaal bericht (C64) (v1)

> Agentkaart. Bron: [catalog.json](../../catalog.json); gegenereerd met `node scripts/build-tool-docs.mjs`. Werk bij inhoudelijke wijzigingen eerst de catalogus, het schema en de runtime bij.

## Toepassingen

- Verhaalintro of instructie tonen
- Retro/computerhistorie-sfeer

## Features

- C64-terminaluitstraling
- Type-effect
- Herstelde tikfouten met |

## Implementatie

tool.js leest een tekstconfiguratie en rendert die teken voor teken in de terminal.

- Runtime: [types/digitaal-bericht/v1/](/types/digitaal-bericht/v1/)
- Configuratieschema: [schema.json](/types/digitaal-bericht/v1/schema.json)
- Voorbeeld: [example.json](/types/digitaal-bericht/v1/example.json)

## Configuratie

Gebruik de JSON die via `?data=<publieke-json-url>` wordt geladen. De schema-URL uit de registry is de norm; de lijst hieronder is er voor snel agent-overzicht.

- `title` (optioneel) — Titel (optioneel): Korte titel die bovenaan/in de meta-regel getoond kan worden.
- `text` (verplicht) — Tekst: Gebruik `|` als backspace. Voor een letterlijk `|` teken: gebruik `||`. Nieuwe regels (Enter) zijn toegestaan.
- `speed` (optioneel) — Snelheid: 1 = normaal. Lager is langzamer, hoger is sneller.
- `mistakes` (optioneel) — Menselijke typfouten: Simuleer af en toe een foute letter + backspace, zodat het 'menselijker' lijkt.
- `mistake_rate` (optioneel) — Typfout-kans: Kans per letter dat er een foutje + backspace gebeurt (alleen bij letters).
- `cursor` (optioneel) — Cursor tonen: Toon een knipperende cursor tijdens het typen.

## API

Statische iframe-API; geen eigen server-endpoint of score-passback.

Algemene iframe-contracten:

- Launch: `/types/digitaal-bericht/v1/?data=<url-encoded JSON-URL>`.
- `unique_id` kan als queryparameter worden meegegeven wanneer de tool instantiecontext of lokale opslag gebruikt; de schema-eis blijft leidend.
- De registry levert `launchUrl`, `schemaUrl` en `exampleDataUrl`; gebruik nooit een onversieerde tool-URL.
- Standalone tools zenden geen `postMessage` en geen Canvas-score terug. Zie [LTI-inzendingen](../../lti-submission.md) voor de grens van die integratie.
