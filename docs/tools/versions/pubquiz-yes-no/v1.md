# Pubquiz Yes/No (v1)

> Agentkaart. Bron: [catalog.json](../../catalog.json); gegenereerd met `node scripts/build-tool-docs.mjs`. Werk bij inhoudelijke wijzigingen eerst de catalogus, het schema en de runtime bij.

## Toepassingen

- Energizer
- Voorkennis checken
- Waar/onwaar-quiz

## Features

- Willekeurige vragen
- Tijdslimiet per vraag
- Random roller
- Slaaggrens
- Optionele gezamenlijke afronding met Opdrachtcertificaat op dezelfde pagina
- Optionele cooldownSeconds met zichtbare afteller tussen pogingen

## Implementatie

app.js kiest en beoordeelt vragen client-side; de sessie leeft alleen in het scherm.

## Configuratie

Gebruik de JSON die via `?data=<publieke-json-url>` wordt geladen. De schema-URL uit de registry is de norm; de lijst hieronder is er voor snel agent-overzicht.

- `cooldownSeconds` (optioneel) — Wachttijd tussen pogingen (seconden): Wachttijd na een antwoordcontrole of volledige quiz, ook na succes. Tijdens de afteller zijn een nieuwe controle en herstart geblokkeerd. Bij 0 of weglaten blijft het bestaande gedrag behouden.
- `title` (verplicht) — Titel: Titel die boven de pubquiz wordt getoond.
- `rollerSeconds` (optioneel) — Rollerduur (seconden): Hoe lang de tool willekeurig door vragen rolt voordat er een vraag gekozen wordt.
- `questionSeconds` (optioneel) — Antwoordtijd (seconden): Hoeveel seconden de student heeft om ja/nee te antwoorden.
- `questionsToAsk` (optioneel) — Aantal te stellen vragen: Hoeveel vragen er in een poging worden gesteld.
- `minCorrectToPass` (optioneel) — Minimaal aantal goede antwoorden: Minimale score die nodig is om het certificaat te behalen.
- `questions` (verplicht) — Vragen: Lijst met ja/nee vragen waaruit willekeurig gekozen wordt.

## API

Statische iframe-API; geen eigen server-endpoint of score-passback. Ondersteunt het same-origin certificaatprotocol via shared/certificate-channel.js; dit geeft geen Canvas-cijfer door.

Algemene iframe-contracten:

- Launch: `/types/pubquiz-yes-no/v1/?data=<url-encoded JSON-URL>`.
- `unique_id` kan als queryparameter worden meegegeven wanneer de tool instantiecontext of lokale opslag gebruikt; de schema-eis blijft leidend.
- De registry levert `launchUrl`, `schemaUrl` en `exampleDataUrl`; gebruik nooit een onversieerde tool-URL.
- Beoordeelbare tools kunnen via het optionele certificaatprotocol `postMessage` gebruiken; er wordt geen Canvas-score teruggestuurd. Zie [LTI-inzendingen](../../lti-submission.md) voor de grens van die integratie.
