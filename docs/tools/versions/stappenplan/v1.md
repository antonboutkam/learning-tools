# Stappenplan (v1)

> Agentkaart. Bron: [catalog.json](../../catalog.json); gegenereerd met `node scripts/build-tool-docs.mjs`. Werk bij inhoudelijke wijzigingen eerst de catalogus, het schema en de runtime bij.

## Toepassingen

- Stapsgewijze instructie
- Visuele handleiding

## Features

- Eén afbeelding en uitleg per stap
- Automatische stapnummering
- Vorige en Volgende
- Navigatie met pijltjestoetsen
- Alt-tekst en melding bij ontbrekende afbeelding

## Implementatie

app.js laadt de JSON-configuratie en toont één stap tegelijk. Relatieve afbeeldingspaden worden opgelost ten opzichte van de geladen JSON-URL. De eerste en laatste stap begrenzen de navigatie.

- Runtime: [types/stappenplan/v1/](/types/stappenplan/v1/)
- Configuratieschema: [schema.json](/types/stappenplan/v1/schema.json)
- Voorbeeld: [example.json](/types/stappenplan/v1/example.json)

## Configuratie

Gebruik de JSON die via `?data=<publieke-json-url>` wordt geladen. De schema-URL uit de registry is de norm; de lijst hieronder is er voor snel agent-overzicht.

- `titel` (optioneel) — Titel: Optionele titel boven het stappenplan.
- `stappen` (verplicht) — Stappen: De stappen in de volgorde waarin de student ze doorloopt.

## API

Statische iframe-API via ?data=<json-url>; geen eigen server-endpoint of score-passback.

Algemene iframe-contracten:

- Launch: `/types/stappenplan/v1/?data=<url-encoded JSON-URL>`.
- `unique_id` kan als queryparameter worden meegegeven wanneer de tool instantiecontext of lokale opslag gebruikt; de schema-eis blijft leidend.
- De registry levert `launchUrl`, `schemaUrl` en `exampleDataUrl`; gebruik nooit een onversieerde tool-URL.
- Beoordeelbare tools kunnen via het optionele certificaatprotocol `postMessage` gebruiken; er wordt geen Canvas-score teruggestuurd. Zie [LTI-inzendingen](../../lti-submission.md) voor de grens van die integratie.
