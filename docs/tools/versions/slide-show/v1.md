# Slide-show (v1)

> Agentkaart. Bron: [catalog.json](../../catalog.json); gegenereerd met `node scripts/build-tool-docs.mjs`. Werk bij inhoudelijke wijzigingen eerst de catalogus, het schema en de runtime bij.

## Toepassingen

- Instructies presenteren
- Automatische presentatie
- Beeld met getimede tekstlagen

## Features

- Automatisch of handmatig afspelen
- Vrije tekstpositionering
- In- en uit-effecten
- Voortgang als bullets/nummers/geen

## Implementatie

app.js normaliseert slides en tekstlagen en speelt ze in de browser af.

- Runtime: [types/slide-show/v1/](/types/slide-show/v1/)
- Configuratieschema: [schema.json](/types/slide-show/v1/schema.json)
- Voorbeeld: [example.json](/types/slide-show/v1/example.json)

## Configuratie

Gebruik de JSON die via `?data=<publieke-json-url>` wordt geladen. De schema-URL uit de registry is de norm; de lijst hieronder is er voor snel agent-overzicht.

- `interval` (verplicht) — Interval (seconden): Standaardduur van elke slide in seconden. Een slide kan hiervan afwijken met de optionele parameter duur.
- `loop` (verplicht) — Herhalen / loop: Begin na de laatste slide automatisch opnieuw bij de eerste slide.
- `automatischStarten` (verplicht) — Automatisch starten: Start de slide-show direct na het laden. Als dit uit staat, kan de gebruiker de slide-show met de afspeelknop starten.
- `voortgang` (verplicht) — Voortgang: Kies hoe de huidige positie in de slide-show wordt weergegeven.
- `slides` (verplicht) — Slides: De slides in de volgorde waarin ze worden afgespeeld.

## API

Statische iframe-API; geen eigen server-endpoint of score-passback.

Algemene iframe-contracten:

- Launch: `/types/slide-show/v1/?data=<url-encoded JSON-URL>`.
- `unique_id` kan als queryparameter worden meegegeven wanneer de tool instantiecontext of lokale opslag gebruikt; de schema-eis blijft leidend.
- De registry levert `launchUrl`, `schemaUrl` en `exampleDataUrl`; gebruik nooit een onversieerde tool-URL.
- Standalone tools zenden geen `postMessage` en geen Canvas-score terug. Zie [LTI-inzendingen](../../lti-submission.md) voor de grens van die integratie.
