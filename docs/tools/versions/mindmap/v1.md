# Mindmap (v1)

> Agentkaart. Bron: [catalog.json](../../catalog.json); gegenereerd met `node scripts/build-tool-docs.mjs`. Werk bij inhoudelijke wijzigingen eerst de catalogus, het schema en de runtime bij.

## Toepassingen

- Brainstormen
- Begrippen verbinden
- Individuele of gezamenlijke woordwebben

## Features

- Sleepbare nodes en verbindingen
- Licht/donker thema
- Automatische layout
- Read-only-modus

## Implementatie

app.js bewaart wijzigingen in localStorage per unique_id; in read-only-modus zijn wijzigingen vanuit de frontend uitgeschakeld.

## Configuratie

Gebruik de JSON die via `?data=<publieke-json-url>` wordt geladen. De schema-URL uit de registry is de norm; de lijst hieronder is er voor snel agent-overzicht.

- `unique_id` (verplicht) — Unieke ID: Unieke sleutel voor deze mindmap-instance. Wordt gebruikt voor persistente opslag wanneer gebruikers de map mogen aanpassen.
- `title` (verplicht) — Titel: Titel boven de mindmap.
- `intro` (optioneel) — Intro (optioneel): Korte uitleg of opdracht boven de mindmap.
- `theme` (verplicht) — Achtergrondthema: Kies of de mindmap een lichte of donkere uitstraling krijgt.
- `readOnly` (verplicht) — Alleen-lezen: Als dit aan staat, kunnen gebruikers niets toevoegen, verwijderen, verbinden of verplaatsen. Als dit uit staat, zijn frontend-bewerkingen en lokale opslag actief.
- `showGrid` (optioneel) — Grid tonen: Toon een subtiel raster op de achtergrond om de mindmap makkelijker uit te lijnen.
- `centerNodeId` (optioneel) — Centrale node-ID (optioneel): ID van het woord dat in het midden van de mindmap moet staan. Laat leeg om automatisch de eerste node of meest verbonden node te gebruiken.
- `autoLayout` (optioneel) — Automatisch radiaal verdelen: Als dit aan staat, zet de tool woorden bij het laden automatisch in ringen rond de centrale node: direct gerelateerd dichtbij, volgende relaties verder naar buiten.
- `spread` (optioneel) — Spreiding: Relatieve afstand tussen bolletjes en clusters. 1 is normaal, lager is compacter en hoger is ruimer.
- `nodes` (verplicht) — Woorden / nodes: De woorden die op de mindmap staan. Gebruik per node een uniek ID; verbindingen verwijzen naar deze IDs.
- `connections` (optioneel) — Verbindingen: Lijnen tussen twee woorden. De velden `from` en `to` verwijzen naar node-IDs uit de lijst hierboven.

## API

Statische iframe-API; geen eigen server-endpoint of score-passback.

Algemene iframe-contracten:

- Launch: `/types/mindmap/v1/?data=<url-encoded JSON-URL>`.
- `unique_id` kan als queryparameter worden meegegeven wanneer de tool instantiecontext of lokale opslag gebruikt; de schema-eis blijft leidend.
- De registry levert `launchUrl`, `schemaUrl` en `exampleDataUrl`; gebruik nooit een onversieerde tool-URL.
- Standalone tools zenden geen `postMessage` en geen Canvas-score terug. Zie [LTI-inzendingen](../../lti-submission.md) voor de grens van die integratie.
