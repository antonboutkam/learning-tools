# Strip ballonnetjes (v1)

> Agentkaart. Bron: [catalog.json](../../catalog.json); gegenereerd met `node scripts/build-tool-docs.mjs`. Werk bij inhoudelijke wijzigingen eerst de catalogus, het schema en de runtime bij.

## Toepassingen

- Stripverhaal met dialoog
- Invuloefening in context
- Sociale situaties bespreken

## Features

- Spraak-, gedachte- en vraagballonnen
- Positie per afbeelding
- Meerdere pagina's
- Variabelen in vervolgtekst

## Implementatie

tool.js rendert pagina's en ballonnen. Antwoorden worden per unique_id in localStorage bewaard en kunnen als {{variabele}} terugkomen.

- Runtime: [types/strip-ballonnetjes/v1/](/types/strip-ballonnetjes/v1/)
- Configuratieschema: [schema.json](/types/strip-ballonnetjes/v1/schema.json)
- Voorbeeld: [example.json](/types/strip-ballonnetjes/v1/example.json)

## Configuratie

Gebruik de JSON die via `?data=<publieke-json-url>` wordt geladen. De schema-URL uit de registry is de norm; de lijst hieronder is er voor snel agent-overzicht.

- `unique_id` (optioneel) — Unieke ID (optioneel): Stabiele unieke sleutel voor deze tool-instance. Hiermee worden antwoorden van verschillende strips apart in localStorage opgeslagen.
- `title` (optioneel) — Titel (optioneel): Titel die boven de strip wordt getoond.
- `debug` (optioneel) — Debug modus: Toon extra info in de UI (handig bij het positioneren).
- `showAllPages` (optioneel) — Toon alle pagina’s tegelijk: Als dit aan staat, worden alle pagina’s onder elkaar getoond. Standaard toont de tool één pagina tegelijk met Vorige/Volgende.
- `pages` (verplicht) — Pagina’s: Elke pagina bestaat uit een afbeelding en één of meer spraak-, gedachte- of vraagballonnen.

## API

Statische iframe-API; geen eigen server-endpoint of score-passback.

Algemene iframe-contracten:

- Launch: `/types/strip-ballonnetjes/v1/?data=<url-encoded JSON-URL>`.
- `unique_id` kan als queryparameter worden meegegeven wanneer de tool instantiecontext of lokale opslag gebruikt; de schema-eis blijft leidend.
- De registry levert `launchUrl`, `schemaUrl` en `exampleDataUrl`; gebruik nooit een onversieerde tool-URL.
- Standalone tools zenden geen `postMessage` en geen Canvas-score terug. Zie [LTI-inzendingen](../../lti-submission.md) voor de grens van die integratie.
