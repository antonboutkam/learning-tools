# Jargonwoorden presenteren (v1)

> Agentkaart. Bron: [catalog.json](../../catalog.json); gegenereerd met `node scripts/build-tool-docs.mjs`. Werk bij inhoudelijke wijzigingen eerst de catalogus, het schema en de runtime bij.

## Toepassingen

- Klassikale jargonverkenning
- Presenteren met peer-feedback
- Actieve woordenschat

## Features

- Docent-, presentatie- en studentweergave
- Woordverdeling en timers
- Naamwijziging ter goedkeuring
- Stemmen en scorebord

## Implementatie

app.js pollt iedere seconde api.php. De PHP-backend bewaart per unique_id een vergrendelde JSON-sessie buiten de document root (configureerbaar via LEARNING_TOOLS_JARGONWOORDEN_STORAGE; anders tijdelijke map).

- Runtime: [types/jargonwoorden-presenteren/v1/](/types/jargonwoorden-presenteren/v1/)
- Configuratieschema: [schema.json](/types/jargonwoorden-presenteren/v1/schema.json)
- Voorbeeld: [example.json](/types/jargonwoorden-presenteren/v1/example.json)

## Configuratie

Gebruik de JSON die via `?data=<publieke-json-url>` wordt geladen. De schema-URL uit de registry is de norm; de lijst hieronder is er voor snel agent-overzicht.

- `aantalWoordenPerStudent` (verplicht) — Aantal woorden per student: Het maximale aantal jargonwoorden dat iedere student krijgt.
- `onderzoektijdPerWoordInSeconden` (verplicht) — Onderzoektijd per woord (seconden): Hoeveel seconden studenten per woord krijgen om de betekenis te onderzoeken.
- `spreektijdInSeconden` (verplicht) — Spreektijd (seconden): De starttijd voor een presentatie. Stemmen voegen 5 seconden toe of trekken 5 seconden af.
- `jargonWoorden` (verplicht) — Jargonwoorden: De lijst met woorden die over de studenten verdeeld wordt.

## API

Live JSON-API: api.php?unique_id=…&action=…. GET state met participantToken; POST init, claim_teacher, join, rename_request, approve_name, start/restart, next_research, spin_student/spin_word, start_time, vote, show_score en finish. teacherToken beschermt docentacties.

Algemene iframe-contracten:

- Launch: `/types/jargonwoorden-presenteren/v1/?data=<url-encoded JSON-URL>`.
- `unique_id` kan als queryparameter worden meegegeven wanneer de tool instantiecontext of lokale opslag gebruikt; de schema-eis blijft leidend.
- De registry levert `launchUrl`, `schemaUrl` en `exampleDataUrl`; gebruik nooit een onversieerde tool-URL.
- Standalone tools zenden geen `postMessage` en geen Canvas-score terug. Zie [LTI-inzendingen](../../lti-submission.md) voor de grens van die integratie.
