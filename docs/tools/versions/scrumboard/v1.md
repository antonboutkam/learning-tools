# Scrumboard (v1)

> Agentkaart. Bron: [catalog.json](../../catalog.json); gegenereerd met `node scripts/build-tool-docs.mjs`. Werk bij inhoudelijke wijzigingen eerst de catalogus, het schema en de runtime bij.

## Toepassingen

- Werk verdelen
- Kanban/sprintbord
- Persoonlijke planning

## Features

- Configureerbare kolommen
- Geeltjes
- Student-items en verwijderen instelbaar
- Breedte-instelling

## Implementatie

tool.js normaliseert het bord en bewaart items in localStorage per key.

- Runtime: [types/scrumboard/v1/](/types/scrumboard/v1/)
- Configuratieschema: [schema.json](/types/scrumboard/v1/schema.json)
- Voorbeeld: [example.json](/types/scrumboard/v1/example.json)

## Configuratie

Gebruik de JSON die via `?data=<publieke-json-url>` wordt geladen. De schema-URL uit de registry is de norm; de lijst hieronder is er voor snel agent-overzicht.

- `key` (verplicht) — Scrumboard key: Unieke sleutel voor opslag. Gebruik dezelfde key om hetzelfde scrumboard opnieuw te openen op andere pagina's.
- `title` (optioneel) — Titel: Titel die boven het scrumboard wordt getoond.
- `allowStudentItems` (optioneel) — Student mag items toevoegen: Zet aan als studenten via de UI zelf geeltjes mogen toevoegen.
- `allowStudentDelete` (optioneel) — Student mag kaartjes verwijderen: Zet aan als studenten via de UI kaartjes van het scrumboard mogen verwijderen.
- `maxWidth` (optioneel) — Maximale breedte: Optionele maximale breedte van het scrumboard, bijvoorbeeld 1200px of 72rem. Laat leeg voor width: 100%.
- `columns` (optioneel) — Kolommen: Kolommen op het scrumboard, van links naar rechts.
- `items` (optioneel) — Vooraf ingevulde items: Optionele startitems voor het scrumboard. Nieuwe of verplaatste items worden daarna per key opgeslagen.

## API

Statische iframe-API; geen eigen server-endpoint of score-passback.

Algemene iframe-contracten:

- Launch: `/types/scrumboard/v1/?data=<url-encoded JSON-URL>`.
- `unique_id` kan als queryparameter worden meegegeven wanneer de tool instantiecontext of lokale opslag gebruikt; de schema-eis blijft leidend.
- De registry levert `launchUrl`, `schemaUrl` en `exampleDataUrl`; gebruik nooit een onversieerde tool-URL.
- Standalone tools zenden geen `postMessage` en geen Canvas-score terug. Zie [LTI-inzendingen](../../lti-submission.md) voor de grens van die integratie.
