## Configuratie

Gebruik de JSON die via `?data=<publieke-json-url>` wordt geladen. De schema-URL uit de registry is de norm; de lijst hieronder is er voor snel agent-overzicht.

- `unique_id` (optioneel) — Unieke instantiecode: Optionele identificatie voor de koppeling met Courses.
- `title` (optioneel) — Titel: Documenttitel voor het browsertabblad; wordt niet boven het bericht getoond.
- `text` (verplicht) — Berichttekst: Platte tekst met alineas. Gebruik | als backspace en || voor een letterlijk pipe-teken.
- `senderLabel` (optioneel) — Afzender: Alleen behouden voor bestaande instanties; wordt niet getoond in de terminal.
- `sentLabel` (optioneel) — Verzendmoment: Alleen behouden voor bestaande instanties; wordt niet getoond in de terminal.
- `statusLabel` (optioneel) — Ontvangststatus: Alleen behouden voor bestaande instanties; wordt niet getoond in de terminal.
- `speed` (optioneel) — Typsnelheid: 1 is het rustige standaardtempo; hoger is sneller. Het basistempo is 50% lager dan de eerdere terminalanimatie.
- `mistakes` (optioneel) — Menselijke typfouten: Toon tijdelijke tikfouten met backspace en af en toe extra puntjes die weer worden gewist.
- `mistake_rate` (optioneel) — Typfoutkans: Kans per letter op een tijdelijke typfout.
- `cursor` (optioneel) — Cursor tonen: Toon tijdens het typen een cursor.

## API

Statische iframe-API; geen eigen server-endpoint of score-passback.

Algemene iframe-contracten:

- Launch: `/types/digitaal-bericht/v2/?data=<url-encoded JSON-URL>`.
- `unique_id` kan als queryparameter worden meegegeven wanneer de tool instantiecontext of lokale opslag gebruikt; de schema-eis blijft leidend.
- De registry levert `launchUrl`, `schemaUrl` en `exampleDataUrl`; gebruik nooit een onversieerde tool-URL.
- Standalone tools zenden geen `postMessage` en geen Canvas-score terug. Zie [LTI-inzendingen](../../lti-submission.md) voor de grens van die integratie.
