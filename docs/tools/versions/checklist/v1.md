# Checklist (v1)

> Agentkaart. Bron: [catalog.json](../../catalog.json); gegenereerd met `node scripts/build-tool-docs.mjs`. Werk bij inhoudelijke wijzigingen eerst de catalogus, het schema en de runtime bij.

## Toepassingen

- Projectstappen afvinken
- Persoonlijke takenlijst
- Controlelijst bij een opdracht

## Features

- Optionele titel en klikbare itemlabels
- Configureerbare beginstatus per item
- Lokale opslag en reset
- Export naar Markdown, tekst en JSON
- Studenten-items toevoegen en verwijderen instelbaar
- Checkboxen links of rechts; tekst altijd links uitgelijnd
- Titel tonen of verbergen
- Readonly-modus met beschikbare links en toegestane export

## Implementatie

app.js laadt JSON via data en rendert een zelfstandige checklist. rememberState bewaart de volledige itemlijst per unique_id (of data-URL) in localStorage. Reset wist de opgeslagen state en herstelt alle startitems. Gewijzigde startitems maken oude voortgang ongeldig. Links worden veilig naar een nieuw tabblad geopend. Het URL-configuratieveld is een gewoon tekstveld, omdat Courses geen apart URL-invoertype ondersteunt. showLabel bepaalt of de checklisttitel zichtbaar is; itemlabels blijven zichtbaar. JSON-export bevat title en de actuele items en kan opnieuw als configuratie worden gebruikt. readOnly blokkeert vinkjes wijzigen, toevoegen, verwijderen, resetten en schrijven naar localStorage; links en toegestane export blijven beschikbaar.

## Configuratie

Gebruik de JSON die via `?data=<publieke-json-url>` wordt geladen. De schema-URL uit de registry is de norm; de lijst hieronder is er voor snel agent-overzicht.

- `unique_id` (optioneel) — Unieke ID (optioneel): Sleutel voor lokale opslag per checklist. De queryparameter unique_id heeft voorrang; zonder ID wordt de volledige data-URL gebruikt.
- `title` (optioneel) — Titel: Titel van de checklist; mag leeg zijn.
- `readOnly` (optioneel) — Readonly: Toon de checklist zonder bewerken: vinkjes wijzigen, toevoegen, verwijderen en resetten zijn uitgeschakeld. Links en toegestane export blijven beschikbaar. Opgeslagen status wordt wel geladen maar niet gewijzigd.
- `rememberState` (optioneel) — Status onthouden: Bewaar vinkjes, toegevoegde items en verwijderingen in localStorage in deze browser. Toont ook Reset om de oorspronkelijke checklist te herstellen. Bij gewijzigde startitems wordt opgeslagen voortgang niet hergebruikt.
- `allowExport` (optioneel) — Export toestaan: Studenten kunnen de actuele checklist downloaden als Markdown, tekst of JSON.
- `allowAddition` (optioneel) — Items toevoegen toestaan: Studenten mogen items met een label en optionele URL toevoegen. Een nieuw item begint niet aangevinkt.
- `allowDeletion` (optioneel) — Items verwijderen toestaan: Studenten mogen bestaande en zelf toegevoegde items verwijderen.
- `checkboxPosition` (optioneel) — Positie checkboxen: Plaats de checkboxen links (left) of rechts (right) van de labels. De tekst blijft altijd links uitgelijnd.
- `showLabel` (optioneel) — Titel tonen: Toon de checklisttitel boven de items. Itemlabels blijven zichtbaar; een lege titel wordt nooit getoond.
- `items` (verplicht) — Checklistitems: Items in de volgorde waarin ze worden getoond. Een lege checklist is toegestaan.

## API

Statische iframe-API via ?data=<JSON-URL>&unique_id=<id>; geen eigen server-endpoint of Canvas-score-passback. Lokale opslag is alleen actief met rememberState. Queryparameter unique_id heeft voorrang op de configuratie; zonder ID wordt de volledige data-URL de opslagsleutel.

Algemene iframe-contracten:

- Launch: `/types/checklist/v1/?data=<url-encoded JSON-URL>`.
- `unique_id` kan als queryparameter worden meegegeven wanneer de tool instantiecontext of lokale opslag gebruikt; de schema-eis blijft leidend.
- De registry levert `launchUrl`, `schemaUrl` en `exampleDataUrl`; gebruik nooit een onversieerde tool-URL.
- Standalone tools zenden geen `postMessage` en geen Canvas-score terug. Zie [LTI-inzendingen](../../lti-submission.md) voor de grens van die integratie.
