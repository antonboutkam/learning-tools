# Stappenplan (v1)

> Agentkaart. Bron: [catalog.json](../../catalog.json); gegenereerd met `node scripts/build-tool-docs.mjs`. Werk bij inhoudelijke wijzigingen eerst de catalogus, het schema en de runtime bij.

## Toepassingen

- Stapsgewijze instructie
- Visuele handleiding
- Analogie en code naast elkaar

## Features

- Uitleg met optionele afbeelding en/of code per stap
- Automatische stapnummering
- Vorige en Volgende
- Navigatie met pijltjestoetsen
- Alt-tekst en melding bij ontbrekende afbeelding
- Tweerichtingssynchronisatie via synchronisatieGroep binnen dezelfde browser en opslagpartitie
- JavaScript-syntaxkleuren; andere taalnamen met ongekleurde weergave
- Letterlijke codefragmenten vet markeren via code.nadruk

## Implementatie

app.js toont één stap tegelijk. Bestaande configuraties met afbeeldingen blijven geldig; afbeelding is nu optioneel. code bevat taal, bron en optioneel nadruk (letterlijke fragmenten, alle voorkomens). code.js maakt veilige DOM-tekst met uitbreidbare tokenizers; JavaScript krijgt basiskleuren voor trefwoorden, strings, commentaar, getallen en vaste waarden. Templates worden als één string gekleurd. Onbekende talen blijven ongekleurd. Code wordt niet uitgevoerd. Relatieve afbeeldingen worden opgelost ten opzichte van de JSON-URL. sync.js koppelt instanties met dezelfde synchronisatieGroep via BroadcastChannel binnen dezelfde tool-origin en browseropslagpartitie. Beide instanties moeten evenveel stappen hebben; nieuwe instanties vragen de huidige stap op. Er is geen synchronisatie tussen apparaten. Zie types/stappenplan/v1/demo.html voor een gekoppeld voorbeeld en types/stappenplan/v1/example-afbeeldingen.json voor het oorspronkelijke afbeeldingsvoorbeeld.

## Configuratie

Gebruik de JSON die via `?data=<publieke-json-url>` wordt geladen. De schema-URL uit de registry is de norm; de lijst hieronder is er voor snel agent-overzicht.

- `titel` (optioneel) — Titel: Optionele titel boven het stappenplan.
- `stappen` (verplicht) — Stappen: De stappen in de volgorde waarin de student ze doorloopt.
- `synchronisatieGroep` (optioneel) — Synchronisatiegroep: Optioneel: geef gekoppelde instanties exact dezelfde unieke groepsnaam, bijvoorbeeld les-variabelen-1. Ze volgen elkaars stap in beide richtingen binnen dezelfde browser en opslagpartitie, vanaf dezelfde tool-origin (protocol, domein en poort). Gebruik evenveel stappen in beide instanties. Geen koppeling tussen apparaten.

## API

Statische iframe-API via ?data=<json-url>; geen eigen server-endpoint of score-passback. Zet synchronisatieGroep in beide JSON-configuraties op dezelfde, per les unieke naam. Stap 1 volgt stap 1, enzovoort. Zonder groep blijft de tool zelfstandig.

Algemene iframe-contracten:

- Launch: `/types/stappenplan/v1/?data=<url-encoded JSON-URL>`.
- `unique_id` kan als queryparameter worden meegegeven wanneer de tool instantiecontext of lokale opslag gebruikt; de schema-eis blijft leidend.
- De registry levert `launchUrl`, `schemaUrl` en `exampleDataUrl`; gebruik nooit een onversieerde tool-URL.
- Beoordeelbare tools kunnen via het optionele certificaatprotocol `postMessage` gebruiken; er wordt geen Canvas-score teruggestuurd. Zie [LTI-inzendingen](../../lti-submission.md) voor de grens van die integratie.
